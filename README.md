# 안전한채팅파일추출 v0.1.2

1. 압축을 풀고 `Chat-TXT-Export` 폴더를 SillyTavern의 `data/default-user/extensions/` 아래에 넣습니다. 사용자 계정을 따로 쓰는 경우 `data/<사용자 계정>/extensions/`에 넣습니다.
2. 실리태번을 새로고침하고 챗을 엽니다.
3. 메시지 입력창 오른쪽의 파일 다운로드 아이콘을 누릅니다. 이전 버전을 쓰고 있다면 같은 폴더에 덮어쓰면 됩니다.

확장 설정의 **안전한채팅파일추출**에서 본문과 파일 형식을 고르거나 입력창 아이콘을 숨길 수 있습니다. 기본값은 번역 우선, 전체 TXT, 입력창 아이콘 표시입니다.

마법봉 메뉴의 **안전한채팅파일추출** 또는 슬래시 명령어 **`/chat-txt-export`**로 같은 설정창을 열 수 있습니다. 설정창에서 **TXT 받기** 또는 **일별 ZIP 받기**를 누르면 다운로드합니다. 빠른답장에 연결하려면 실행 내용에 `/chat-txt-export`를 넣으세요.

각 턴은 저장된 화자 이름, 본문, `----------` 한 줄 순으로 출력됩니다. 턴 사이는 빈 줄 하나를 둡니다. 선택한 본문의 태그, 동적패널 코드, 문단 줄바꿈을 보존합니다. 내보내기는 브라우저에서 처리하며 챗과 번역 데이터를 수정하지 않습니다.

## 일별 TXT

인포블럭 태그와 날짜 형식을 등록합니다. 같은 태그에 여러 형식을 등록할 수 있습니다. `YYYY`는 네 자리 연도이며 `MM`과 `DD`는 한 자리와 두 자리 숫자를 모두 읽습니다.

| 인포블럭 태그 | 날짜 형식 |
| --- | --- |
| Scene_Info | Date: YYYY.MM.DD |
| info_panel | 날짜: YYYY/MM/DD |
| Scene_Info | Date: MM-DD-YYYY |

위 표의 첫 두 규칙은 기본 등록되어 있습니다. 날짜는 원문의 인포블럭에서 읽습니다. 새 날짜가 적힌 메시지부터 해당 날짜 파일에 쓰고, 날짜 정보가 없는 메시지는 직전에 확인한 날짜를 이어받습니다. **첫 날짜 이전 메시지도 첫날 파일에 포함**을 켜면 첫 날짜가 나오기 전의 메시지를 첫날 파일 맨 앞에 넣습니다. 기본값은 꺼짐이며, 이때는 첫 날짜 전의 메시지를 `날짜 미지정.txt`에 저장합니다. 챗에서 날짜를 하나도 읽지 못하면 옵션과 상관없이 `날짜 미지정.txt`에 저장합니다. ZIP 안의 날짜별 파일명은 `YYYY-MM-DD.txt` 형식입니다.

번역은 실리태번 기본 번역과 Cat Translator Lab에서 메시지에 저장하는 필드를 읽습니다. 기본 번역의 페르소나 메시지에 원문과 표시문이 모두 있으면 자동 발신 번역의 저장 방식으로 해석합니다.
